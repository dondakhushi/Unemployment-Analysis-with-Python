# Unemployment Analysis with Python

## 📌 Project Overview

Unemployment is one of the most important economic indicators that reflects the health of a country's economy. This project analyzes unemployment trends using Python by exploring unemployment rate data, identifying patterns, and studying the impact of the COVID-19 pandemic on employment levels.

The project includes data cleaning, exploratory data analysis (EDA), visualization, and insights that can help policymakers understand unemployment trends and make informed decisions.

---

## 🎯 Objectives

* Analyze unemployment rate data representing the percentage of unemployed people.
* Perform data cleaning and preprocessing.
* Explore unemployment trends using statistical analysis.
* Visualize unemployment rates across regions and time periods.
* Investigate the impact of COVID-19 on unemployment.
* Identify seasonal and regional patterns.
* Generate insights useful for economic and social policy planning.

---

## 📂 Dataset

The dataset contains unemployment statistics for different regions and time periods.

### Features

* Region
* Date
* Frequency
* Estimated Unemployment Rate (%)
* Estimated Employed
* Estimated Labour Participation Rate (%)

## 🔍 Key Findings

* Unemployment rates increased significantly during the COVID-19 pandemic.
* Some regions consistently experienced higher unemployment than others.
* Employment levels dropped during lockdown periods.

* Labour participation rates were affected by economic disruptions.
